🎮 Hangman Game in Python
📌 Project Description

Hangman is a simple text-based word-guessing game developed using Python. The computer randomly selects a word from a predefined list of five words, and the player must guess the word one letter at a time.

The game displays underscores for hidden letters and reveals the correct letters as the player guesses them. The player is allowed a maximum of six incorrect guesses. The objective is to guess the complete word before running out of attempts.

This beginner-friendly project demonstrates fundamental Python programming concepts, including random selection, loops, conditional statements, strings, lists, and user input.

✨ Features
🎲 Random word selection from five predefined words
🔤 Guess the word one letter at a time
❤️ Maximum of six incorrect guesses
✅ Displays correctly guessed letters
⚠️ Validates user input
🔁 Prevents repeated guesses from counting as new attempts
🏆 Displays the result when the game ends
💻 Simple console-based interface

🚀 How to Run the Game
Prerequisites

Install Python 3 on your computer.

Steps
Clone or download this repository.
Open a terminal in the project folder.
Run the following command:
python hangman.py


On some Windows computers, use:

py hangman.py

Enter one letter at a time when prompted.
Continue guessing until you win or use all six incorrect attempts.
🎯 How to Play
The computer chooses a random word.
The word is displayed as underscores.
Enter a single letter to guess the word.
Correct guesses reveal the matching letters.
Incorrect guesses reduce the remaining attempts.
Guess the complete word to win the game.
If you make six incorrect guesses, the game ends and reveals the word.
